## 1. 시스템 소개

### 1.1 시스템 개요
보이스피싱 탐지 시스템은 AI 기술을 활용하여 업로드된 음성 파일을 분석하고 보이스피싱 위험을 판단하는 웹 기반 서비스입니다. VITO STT API, 머신러닝 모델, KoBERT 딥러닝 모델을 통해 다단계 분석을 수행하여 정확한 피싱 여부를 식별합니다.

### 1.2 주요 기능
- 음성 파일 업로드 및 분석 (mp3, wav, amr, m4a 지원)
- 1차 2차 연동 탐지를 통한 정확한 분석
- 직관적인 웹 인터페이스
- 분석 결과 및 경고 메시지 제공
- 사용자 피드백 수집 시스템
- 분석 통계 확인

### 1.3 분석 과정
1. **1단계**: 음성 파일 업로드
2. **2단계**: STT(Speech-to-Text) 변환
3. **3단계**: 1차 ML 모델 분석
4. **4단계**: 2차 DL 모델 검증
5. **5단계**: LLM 맞춤형 경고 생성
6. **6단계**: 최종 결과 확인

## 3. 시스템 사용 방법 (단일 페이지 애플리케이션)

### 3.1 시스템 접속 및 시작
1. http://localhost:8000/ 접속
2. 접속하면 바로 업로드 화면이 표시됩니다
3. 별도의 메인 페이지나 로그인 과정이 없습니다

### 3.2 음성 파일 업로드 및 분석 (1단계)

**화면 구성**:
1. 화면 상단에 "woogawooga" 제목과 "음성 파일 업로드" 안내 표시

**파일 업로드 방법** (2가지):
- **방법1**: "파일 선택" 버튼 클릭 후 음성 파일 선택
- **방법2**: 파일을 드래그앤드롭 영역에 직접 드래그

**지원 파일 형식 및 통화 길이**:

| 파일 형식 | 확장자 | 최대 크기 | 예상 통화 길이 (품질별) |
|----------|--------|-----------|------------------------|
| AMR | .amr | 50MB | 약 400-500분 (저품질 압축) |
| MP3 | .mp3 | 50MB | 약 60-120분 (일반 품질 128kbps 기준) |
| WAV | .wav | 50MB | 약 4-6분 (고품질 무압축) |
| M4A | .m4a | 50MB | 약 80-150분 (중간 품질 압축) |

**분석 시작**:
4. 파일 선택 후 "분석 시작" 버튼 활성화
5. "분석 시작" 버튼 클릭 시 분석 진행 화면으로 자동 전환

### 3.3 분석 진행 확인 (2단계)
1. 화면이 자동으로 "음성 파일 분석" 단계로 전환
2. 진행률 바와 분석 상태 메시지 표시
3. "분석을 준비하고 있습니다..." → "분석 진행 중..." 등 상태 업데이트
4. 분석 완료 시 자동으로 결과 화면으로 전환

### 3.4 분석 결과 확인 (3단계)

**주요 결과 정보**:
1. "분석 결과" 화면에서 다음 정보 확인:
   - 최종 분석 결과 (정상/보이스피싱)
   - 피싱 유형 (기관사칭형, 대출사기형 등)
   - 경고 메시지

**피드백 제출**:
2. 피드백 제출:
   - "분석 결과가 정확한가요?" 질문에 라디오 버튼으로 응답
   - 추가 의견 텍스트 입력 (선택사항)
   - "피드백 제출" 버튼으로 의견 전송

**다음 작업**:
3. 다음 작업:
   - "다시 분석" 버튼: 새로운 파일 분석을 위해 업로드 화면으로 돌아가기

### 3.5 오류 처리 (4단계 - 조건부)
1. 분석 중 오류 발생 시 "분석 실패" 화면 표시
2. 오류 메시지 확인
3. "재시도" 또는 "새 파일 업로드" 버튼으로 다시 시작

### 3.6 통계 페이지 이용 (별도 페이지)
- **주소**: /statistics/ (직접 URL 입력으로 접속)
- **확인 가능 정보**:
  - 총 분석 건수
  - 보이스피싱 탐지 건수
  - 정상 통화 건수
  - 피싱 탐지율

## 4. 분석 결과 이해하기

### 4.1 분석 결과 해석
- **정상 통화**: 보이스피싱 위험이 낮은 일반적인 통화
- **보이스피싱**: 사기 전화로 판별된 위험한 통화

### 4.2 신뢰도 해석

| 신뢰도 범위 | 해석 | 권장 조치 |
|------------|------|-----------|
| 0.0 ~ 0.3 | 낮은 신뢰도 | 추가 확인 권장 |
| 0.4 ~ 0.6 | 보통 신뢰도 | 주의 깊은 검토 |
| 0.7 ~ 0.8 | 높은 신뢰도 | 신뢰할 만한 결과 |
| 0.9 ~ 1.0 | 매우 높은 신뢰도 | 높은 정확도 |

### 4.3 주요 보이스피싱 유형
- **기관사칭형**: 경찰, 검찰, 금융감독원 등 공공기관 사칭
- **대출사기형**: 대출 관련 허위 정보로 속이는 유형
- **금융사칭형**: 은행, 카드사 등 금융기관 사칭
- **기타**: 다양한 형태의 보이스피싱

### 4.4 주요 의심 키워드

| 카테고리 | 키워드 예시 |
|---------|-------------|
| 기관 사칭 | 경찰청, 검찰청, 금융감독원, 은행 등 |
| 금융 관련 | 계좌이체, 보안카드, OTP, 공인인증서 등 |
| 긴급성 조장 | 긴급, 즉시, 오늘 중, 지금 당장 등 |
| 개인정보 요구 | 주민번호, 계좌번호, 비밀번호 등 |

## 5. 문제 해결

### 5.1 일반적인 오류 및 해결방법

| 문제 상황 | 원인 | 해결방법 |
|-----------|------|----------|
| 파일 업로드가 안 됨 | 지원하지 않는 파일 형식 | MP3, WAV, AMR, M4A 형식의 파일을 사용하세요 |
| "파일 크기가 너무 큽니다" 오류 | 50MB를 초과하는 파일 | 파일 크기를 50MB 이하로 줄이거나 분할하세요 |
| "STT 처리에 실패했습니다" 메시지 | VITO API 오류 또는 음성 품질 문제 | 잠시 후 다시 시도하거나 더 명확한 음성 파일을 사용하세요 |
| 분석이 완료되지 않음 | 서버 처리 오류 | 페이지를 새로고침하고 다시 시도하세요 |
| 피드백 제출이 안 됨 | 네트워크 연결 문제 | 인터넷 연결을 확인하고 다시 시도하세요 |

### 5.2 브라우저 관련 문제
- **JavaScript가 비활성화된 경우**: 브라우저 설정에서 JavaScript 활성화
- **쿠키 차단된 경우**: 사이트의 쿠키 허용 설정
- **캐시 문제**: 브라우저 캐시 삭제 후 재접속

### 5.3 기술 지원
시스템 관련 문의나 버그 신고가 있으시면 개발팀에게 연락주세요.
- 상세한 오류 상황 및 재현 단계를 포함하여 문의해 주세요.
