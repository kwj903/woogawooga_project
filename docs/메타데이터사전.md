## 5. 클래스(범주) 정의

### 5.1 보이스피싱 유형 분류 (phishing_type)

| 클래스(라벨) | 설명 |
|-------------|------|
| 기관사칭형 | 검찰, 경찰, 금융감독원 등 공공기관을 사칭하여 개인정보, 계좌이체 요구 |
| 대출빙자형 | 저금리 대출, 대환대출, 신용등급 상승 등을 명목으로 선입금이나 수수료 요구 |
| 메신저피싱형 | 가족, 지인을 사칭하여 메신저로 금전을 요구하는 유형 |
| 택배사칭형 | 택배 배송, 반품, 관세 등 명목으로 악성앱 설치 유도 및 개인정보 탈취 |
| 가족지인사칭형 | AI로 가족 목소리 복제, 자녀 납치, 사고 등 긴박한 상황 연출하여 송금 유도 |
| 투자권유형 | 주식, 가상자산, NFT 등 고수익 투자 명목으로 접근, 송금 및 투자금 요구 |
| 세금환급형 | 국세청, 지방세 등 세금 환급. 환급금 수령 명목으로 개인정보나 계좌 요구 |
| 콜백스미싱형 | 결제 취소, 쇼핑몰 주문 등 문자로 유도 후 전화 연결, 악성앱 설치 유도 |

## 7. 데이터셋 분할 (학습/검증/테스트)

| 파일명 | 원본 데이터 | 목적 | file_id 수 | 분할 비율 | 분할 방법 |
|--------|-------------|------|-----------|----------|----------|
| train.csv | phishing_data.csv<br/>normal_data.csv | AI 모델 학습 | 8,000건 | 80% | Stratified Sampling |
| validation.csv | phishing_data.csv<br/>normal_data.csv | 모델 성능 검증 및 튜닝 | 1,000건 | 10% | Stratified Sampling |
| test.csv | phishing_data.csv<br/>normal_data.csv | 최종 모델 성능 평가 | 1,000건 | 10% | Stratified Sampling |

### 7.1 주요 용어 설명

**Stratified Sampling (계층적 샘플링)**

원본 데이터의 클래스 비율(예: 피싱 vs 일반 대화 비율)을 학습/검증/테스트 셋에서도 동일하게 유지하며 나누는 방법으로, 분류 모델에서 가장 일반적으로 사용됩니다.

## 8. 데이터 품질 관리

### 8.1 데이터 검증 기준

| 검증 항목 | 기준 | 비고 |
|----------|------|------|
| 중복 데이터 | file_id 기준 중복 제거 | 동일한 대화 내용의 중복 방지 |
| 누락 데이터 | raw_text 필수 입력 | 빈 텍스트 데이터 제외 |
| 라벨 일관성 | phishing_type과 is_phishing 일치 | 피싱 유형이 있는 경우 is_phishing=1 |
| 텍스트 길이 | 최소 10자 이상 | 너무 짧은 발화 제외 |

### 8.2 전처리 과정

| 단계 | 처리 내용 | 목적 |
|------|----------|------|
| 1. 데이터 정제 | 특수문자, HTML 태그 제거 | 노이즈 제거 |
| 2. 정규화 | 공백, 줄바꿈 통일 | 일관된 형식 유지 |
| 3. 토큰화 | 형태소 분석 및 토큰 분리 | 자연어 처리 준비 |
| 4. 라벨 검증 | 클래스 라벨 유효성 검사 | 데이터 품질 보장 |

## 9. 성능 지표 및 평가 방법

### 9.1 평가 지표

| 지표 | 설명 | 활용 목적 |
|------|------|----------|
| Accuracy | 전체 예측 중 정확한 예측 비율 | 전반적 성능 측정 |
| Precision | 피싱으로 예측한 것 중 실제 피싱 비율 | 오탐지율 최소화 |
| Recall | 실제 피싱 중 올바르게 탐지한 비율 | 미탐지율 최소화 |
| F1-Score | Precision과 Recall의 조화평균 | 균형잡힌 성능 평가 |

### 9.2 모델 성능 목표

| 지표 | 목표 값 | 최소 기준 |
|------|--------|----------|
| Accuracy | ≥ 95% | ≥ 90% |
| Precision | ≥ 93% | ≥ 85% |
| Recall | ≥ 95% | ≥ 90% |
| F1-Score | ≥ 94% | ≥ 87% |
