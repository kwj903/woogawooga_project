v0.dev 프롬프트:

50대 이상 사용자를 위한 보이스피싱 탐지 모바일 앱 UI를 만들어주세요. 기존 웹앱을 참고하여 다음 요구사항을 반영해주세요:

**핵심 기능:**
- 음성 파일 업로드 (AMR, MP3, WAV, M4A 지원)
- 실시간 분석 진행률 표시
- 보이스피싱 판단 결과 표시
- 사용자 피드백 수집

**디자인 요구사항:**
1. **50대+ 사용자 친화적 설계**
   - 글자 크기: 최소 18px 이상, 중요한 정보는 24px+
   - 버튼 크기: 최소 44px 높이 (터치하기 쉽게)
   - 충분한 여백과 명확한 구분선
   - 단순하고 직관적인 네비게이션

2. **색상 스키마**
   - 기본: 차분한 파란색 계열 (#2563eb)
   - 보이스피싱 경고: 빨간색 (#dc2626)
   - 정상 판정: 초록색 (#059669)
   - 배경: 연한 그라데이션 (#f0f9ff → #e0e7ff)

3. **주요 화면 구성**
   - **메인/업로드 화면**: "woogawooga" 로고, 방패 아이콘, 드래그&드롭 영역
   - **분석 화면**: 진행률 바, 실시간 상태 메시지
   - **결과 화면**: 판정 결과 (큰 글씨), 경고 메시지, 피드백 옵션
   - **오류 화면**: 재시도/새 파일 버튼

4. **UX 특징**
   - 카드 기반 레이아웃 (둥근 모서리, 그림자 효과)
   - 명확한 아이콘과 텍스트 조합
   - 단계별 브레드크럼 네비게이션
   - 터치 친화적 인터페이스

5. **모바일 최적화**
   - 반응형 디자인
   - 세로 모드 우선 설계
   - 한 손으로 조작 가능한 레이아웃
   - 빠른 로딩과 심플한 애니메이션

**참고 스타일**: 현재 웹앱은 깔끔한 카드 UI, 부드러운 색상 전환, 직관적인 아이콘 사용이 특징입니다. 이를 모바일 앱으로 전환하되 중장년층이 쉽게 사용할 수 있도록 더 큰 요소들과 명확한 시각적 피드백을 제공해주세요.

**추가 요청사항:**
- React/Next.js 기반으로 구현
- Tailwind CSS 사용
- 반응형 모바일 퍼스트 디자인
- 접근성(Accessibility) 고려
- 간단한 애니메이션 효과 포함
