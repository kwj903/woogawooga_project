# Django 프로젝트 구조 분석 보고서

## 1. 프로젝트 개요

**프로젝트명**: woogawooga_project
**목적**: AI 기반 보이스피싱 탐지 시스템
**Django 버전**: 5.2.4
**분석일**: 2025-07-27

이 프로젝트는 음성 파일을 분석하여 보이스피싱 여부를 판단하는 웹 애플리케이션입니다. 1차 머신러닝 모델과 2차 딥러닝 모델을 연동하여 높은 정확도의 분석 결과를 제공합니다.

## 2. 프로젝트 구조

```
woogawooga_project/
├── config/                 # Django 설정 패키지

│   ├── models.py          # 데이터베이스 모델
│   ├── views.py           # 뷰 함수들

│   └── migrations/        # 데이터베이스 마이그레이션
```

## 4. 메인 애플리케이션 (woogawooga)

### 4.1 데이터베이스 모델

#### ProcessdFile (처리된 파일)
- `ocrn_no`: 발생번호 (기본키)
- `transcript`: 전사내용
- `prcs_cont_1`: 1차 전처리내용
- `file_path`: 파일경로

#### InferenceResult (추론 결과)  
- `rslt_id`: 결과ID
- `ml_rslt_cd`: ML결과코드 (0=정상, 1=피싱)
- `prdt_scr`: 예측점수
- `phsh_tp_nm`: 피싱유형명
- `warn_cn`: 경고내용

#### Feedback (피드백)
- `prp_no`: 제안번호
- `prdt_rslt_yn`: 예측결과여부
- `wropn_cn`: 의견내용

### 4.2 주요 뷰 함수

#### analyze 뷰 - 메인 분석 API
1. 파일 검증 (크기, 형식)
2. VITO STT 처리
3. 텍스트 전처리 (KiWi 형태소 분석)
4. 1차 모델 분석 (Stacking)
5. 2차 모델 분석 (LightGBM) - 조건부
6. LLM 설명 생성 (GPT-4o)
7. 데이터베이스 저장

#### 핵심 분석 로직
- **보류 구간**: 0.3~0.75 확률에서 2차 모델 실행
- **즉시 판별**: 0.3 이하(정상), 0.75 이상(피싱)

### 4.3 URL 패턴
- `/`: 메인 페이지
- `/upload/`: 업로드 페이지
- `/analyze/`: 분석 API
- `/submit_feedback/`: 피드백 API
- `/statistics/`: 통계 페이지

## 6. 데이터 처리 플로우

```
파일 업로드 → STT → 전처리 → 1차 ML → [2차 DL] → LLM → DB 저장 → 응답
```

1. 음성 파일 업로드 및 검증
2. VITO API로 음성-텍스트 변환
3. KiWi 형태소 분석 + TF-IDF 벡터화
4. Stacking 모델로 1차 분석
5. 보류 구간시 LightGBM으로 2차 분석
6. GPT-4o로 유형 분류 및 경고 생성
7. 다중 테이블 저장 및 JSON 응답
